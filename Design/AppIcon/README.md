# Chef icon for Icon Composer

Traced from the reference (chef hat, crossed fork and spoon, gear), 1024 x 1024, white artwork on a transparent canvas.

- `1-hat.svg`, `2-fork.svg`, `3-spoon.svg`, `4-gear.svg`: one layer each. Drop them into Icon Composer as separate layers, in this order (spoon above fork), so each can get its own depth and glass.
- `chef-icon-glyph.svg`: all four in one file, if you want a single layer.
- `chef-icon-preview.svg` / `.png`: with the reference's background colour (#253238), for a look before importing. In Icon Composer set the background as a fill instead.

The fork runs unbroken through the crossing (the reference had a gap where the spoon passed over it). No drop shadow: Icon Composer adds its own.
